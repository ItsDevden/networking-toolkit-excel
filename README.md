# Networking Toolkit — Excel

I’m studying to become a data technician. On a slow day at school, I challenged myself to build the networking tools I needed in Excel. Now I use it because I’m lazy enough to automate the calculations, tho have moved on to using my [Windows app version](https://github.com/ItsDevden/NetworkingToolkit) mostly instead.

## Features

- Binary, decimal and hex converters
- A 16-bit binary breakdown
- VLSM planner with prefixes, network IDs, usable IP ranges and broadcast addresses
- Reset buttons

Download the **.xlsm** and enable macros. For VLSM, enter an aligned starting network ID and your host requirements **largest first**, with no empty rows.
